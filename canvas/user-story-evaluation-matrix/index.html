What it does

Why this canvas exists

A competitive analysis that starts from the user rather than the feature list. Down the side go the user stories you learned from research — “as a [who], I need to [what] so that [why]”. Across the top go the real alternatives, including the spreadsheet and doing nothing. Each cell is scored on how well that alternative serves that story. The pattern in the grid tells you three things at once: where every competitor is strong (table stakes you must match), where they are all weak (your opening), and which stories nobody else has even noticed (your category).

Reach for it when
  • Before committing a roadmap, to check you are building where the gap is.
  • When a competitive slide is needed for investors or a board and the usual feature checklist feels dishonest.
  • After an empathy canvas or interview round, to turn stories into priorities.

Built for: Product managers and founders deciding what to build first, and anyone writing a competitive slide that needs to be true.

Box by box

The short version

The full guide in the pack adds what good looks like for each box, a worked example, the agenda and the mistakes.

01the rows — user stories — Write eight to twelve stories from research, in the form: as a [who], I need to [what], so that [why]. Order them by how often they came up.
02the columns — competitors — List the real alternatives your user has today: direct competitors, indirect ones, the spreadsheet, and doing nothing.
03the scores — Score every cell 0–3 with evidence: a demo, a review, a customer interview. Colour the cells.
04reading the grid — Find the columns of 3s (table stakes), the rows of 0s (nobody serves this) and the rows where scores disagree (contested).
05your column — Add yourself as the last column and score honestly, today — not the roadmap.
